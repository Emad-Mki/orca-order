# قواعد استيراد المنتجات

- الوحدة الأولى هي وحدة الأساس في المخزون والطلب.
- المنشأ يجب أن يكون: وطني أو هندي أو صيني.
- العملة الافتراضية USD عند ترك الحقل فارغاً.
- السعر في الملف هو سعر عرض للزبون، بينما السعر النهائي يضعه المحاسب في الفاتورة.
- الكمية السالبة تسجل كنقص جرد وتحتاج مراجعة، ولا تظهر ككمية متاحة.
- رمز المادة فريد ولا يسمح بتكراره.
- كمية الوحدة الثانية = كمية الأساس ÷ عامل تحويل الوحدة الثانية، والثالثة بنفس الطريقة.

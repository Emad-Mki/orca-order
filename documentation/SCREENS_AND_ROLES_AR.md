# الشاشات والصلاحيات (ملخص)

## الزبون
- المنتجات: بحث برمز المادة أو الاسم أو المجموعة.
- الأسعار: يرى سعر العرض من ملف المنتجات.
- الطلبية: إنشاء مسودة، تعديل البنود، إرسال الطلب.
- الفاتورة المسعّرة: رؤية السعر النهائي بعد تسعير المحاسب، مع إمكانية الحذف أو زيادة الكميات قبل التأكيد.

## المحاسب
- الطلبات الجديدة والتسعير والاعتماد.
- إنشاء العملاء وحساباتهم.
- إدارة الأسعار والحسومات.
- تسجيل الدفعات (نقدي، حوالة، شام كاش).
- تسجيل الشحن: شركة الشحن، المحافظة، عدد الطرود، رمز التتبع الاختياري، أجور الشحن الداخلية.

## مدير المستودع
- مشاهدة المنتجات والكميات فقط دون أسعار.
- استلام مواد وزيادة المخزون.
- طلب مواد ناقصة.
- تجهيز الفواتير وتسجيل عدد الطرود (إجمالي، كراتين، أكياس) وملاحظات التجهيز.

## المدير
- جميع صلاحيات المحاسب والمستودع.
- إدارة المستخدمين والأدوار.
- مراجعة سجل التدقيق والتقارير.
- ضبط إعدادات التطبيق الأساسية.
